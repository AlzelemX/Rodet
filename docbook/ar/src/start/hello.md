# مرحبا يا عالم!

أنشئ ملفًا اسمه `main.rs`:

```rust
fn main() {
    out!("Hello, world!");
}
```

ترجمه وشغّله:

```text
> rustc main.rs
> ./main          (on Windows: .\main.exe)
Hello, world!
```

## معنى كل جزء

- `fn main()` — دالة اسمها `main`. كل برنامج يبدأ من هنا.
- `{ ... }` — جسم الدالة.
- `out!("...")` — يطبع سطرًا. علامة `!` تعني أن `out!` *ماكرو*: كود يكتب
  كودًا عنك.
- `;` — تنهي الجملة.

> **جديد في Rust++:** `out!` يطبع سطرًا. يعمل تمامًا مثل `println!` في Rust،
> و`println!` ما زال يعمل أيضًا.

## طباعة القيم

ضع `{}` في المكان الذي تريد فيه القيمة، أو اسم المتغير داخل `{}`:

```rust
fn main() {
    let name = "Sara";
    let age = 25;

    out!("{name} is {age} years old");
    out!("{} + {} = {}", 2, 3, 2 + 3);
    out!();                        // سطر فارغ
    out!("{:?}", [1, 2, 3]);       // {:?} يطبع القوائم والبيانات الأخرى
    out!("{:.2}", 3.14159);        // رقمان بعد الفاصلة: 3.14
}
```

```text
Sara is 25 years old
2 + 3 = 5

[1, 2, 3]
3.14
```

ماكروهات طباعة أخرى:

| الماكرو | ماذا يفعل |
|---|---|
| `out!` | يطبع سطرًا |
| `print!` | يطبع بدون سطر جديد |
| `eprintln!` | يطبع سطرًا في مخرج الأخطاء |
| `format!` | يصنع `String` بدلًا من الطباعة |
