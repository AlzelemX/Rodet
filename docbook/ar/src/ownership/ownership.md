# الملكية

الملكية هي طريقة Rodet في إدارة الذاكرة **بدون جامع نفايات وبدون أن تستدعي
`free` بنفسك**. هي الفكرة الوحيدة التي تجعل Rodet سريعة وآمنة معًا، فخذ وقتك
مع هذا الفصل.

## ثلاث قواعد

1. لكل قيمة **مالك واحد**: المتغير الذي يحملها.
2. عندما يختفي المالك (تنتهي كتلة `{ }` الخاصة به)، تُحرَّر القيمة.
3. إعطاء القيمة لغيرك **ينقلها**: المتغير القديم لا يستطيع استخدامها بعد ذلك.

```rust
fn main() {
    {
        let s = String::from("hello"); // s يملك النص
        out!("{s}");
    }                                  // انتهت الكتلة: حُرِّر النص
}
```

لا تسرّب للذاكرة (القيمة تُحرَّر دائمًا) ولا تحرير مزدوج (مالك واحد فقط
يحررها). المترجم يتحقق من هذا؛ ولا يكلف شيئًا وقت التشغيل.

## النقل

```rust,compile_fail
fn main() {
    let a = String::from("hello");
    let b = a;           // النص ينتقل من `a` إلى `b`
    out!("{a}");         // خطأ: استعارة `a` بعد نقله
}
```

لماذا؟ لو امتلك `a` و`b` النص معًا، لحرّره كل منهما. لذلك يعطي `a` النص
ويصبح غير قابل للاستخدام.

نفس الشيء يحدث عندما تعطي قيمة لدالة:

```rust
fn shout(text: String) {
    out!("{}!", text.to_uppercase());
}   // يُحرَّر `text` هنا

fn main() {
    let msg = String::from("hi");
    shout(msg);           // `msg` ينتقل إلى الدالة
    // out!("{msg}");     // خطأ: `msg` نُقل
}
```

## Copy: القيم الصغيرة تُنسخ ولا تُنقل

الأرقام و`bool` و`char`، والصفوف والمصفوفات منها، صغيرة، فتُنسخ بدلًا من
النقل:

```rust
fn main() {
    let x = 5;
    let y = x;           // نسخ
    out!("{x} {y}");     // الاثنان يعملان
}
```

## clone: النسخ عن قصد

لتحصل فعلًا على نسختين من `String` أو `Vec`، اطلب ذلك بـ `.clone()`. يظهر في
الكود، فترى دائمًا أين تُنسخ الذاكرة:

```rust
fn main() {
    let a = String::from("hello");
    let b = a.clone();
    out!("{a} {b}");
}
```

## الفرق بين String و &str

- `String` **يملك** نصه. يمكن أن يكبر ويتغير.
- `&str` **يستعير** نصًا يملكه غيره (`String`، أو نص مكتوب في البرنامج).

معظم الدوال تحتاج فقط أن تقرأ النص، فتأخذ `&str`. هذه هي *الاستعارة*،
موضوع الفصل التالي.
