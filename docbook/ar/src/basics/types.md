# الأنواع

لكل قيمة نوع. النوع يخبر المترجم كم تحتاج القيمة من الذاكرة وماذا يمكنك أن
تفعل بها.

## الأرقام

| النوع | يحمل | مثال |
|---|---|---|
| `i32` | أعداد صحيحة، من −2 147 483 648 إلى 2 147 483 647 (الافتراضي) | `-7` |
| `i64` | أعداد صحيحة أكبر | `9_000_000_000` |
| `u8`، `u32`، `u64` | أعداد صحيحة، لا تكون سالبة أبدًا | `255` |
| `usize` | الأحجام والمواضع في القوائم | `v.len()` |
| `f64` | أعداد بفاصلة عشرية (الافتراضي) | `3.14` |
| `f32` | مثل `f64` لكن أصغر وأقل دقة | `1.5` |

`i` = يمكن أن يكون سالبًا، `u` = بدون إشارة (من 0 فما فوق)، والرقم = عدد البِتّات.

```rust
fn main() {
    let a = 10;           // i32
    let b = 3.0;          // f64
    let big = 1_000_000;  // علامة _ تجعل الأرقام الكبيرة سهلة القراءة

    out!("{}", a / 3);    // 3   (قسمة أعداد صحيحة)
    out!("{}", a % 3);    // 1   (باقي القسمة)
    out!("{}", b / 2.0);  // 1.5
    out!("{}", a as f64 / 4.0); // 2.5  (`as` يحوّل النوع)
    out!("{big}");
}
```

الأرقام من أنواع مختلفة لا تختلط بالخطأ: `a + b` في المثال خطأ حتى تحوّل
واحدًا منهما بـ `as`. لا ضياع للدقة بدون أن تعلم.

## صح وخطأ (true و false)

```rust
fn main() {
    let ready: bool = true;
    let big = 10 > 5; // true
    out!("{} {} {}", ready && big, ready || false, !ready);
}
```

## الحروف والنصوص

```rust
fn main() {
    let letter: char = 'R';     // حرف واحد، بين علامتي تنصيص مفردتين
    let arabic = 'ع';           // أي لغة، وأي رمز تعبيري
    let fixed: &str = "hello";  // نص مكتوب في البرنامج
    let mut owned = String::from("hello"); // نص يمكن تكبيره
    owned.push_str(", world");

    out!("{letter} {arabic} {fixed} {owned}");
    out!("{}", owned.len()); // الطول بالبايت: 12
}
```

الفرق بين `&str` و`String` مشروح في [الملكية](../ownership/ownership.md).
الآن يكفي: `"..."` من النوع `&str`؛ واستخدم `String` عندما يتغير النص.

## الصفوف (tuples) والمصفوفات

```rust
fn main() {
    let point: (i32, i32) = (3, 4);   // صف: مجموعة ثابتة، أي أنواع
    let (x, y) = point;               // فكّه إلى أجزاء
    out!("x={x} y={y} first={}", point.0);

    let days = ["Sat", "Sun", "Mon"]; // مصفوفة: طول ثابت، نوع واحد
    out!("{} of {}", days[0], days.len());

    let zeros = [0; 5];               // [0, 0, 0, 0, 0]
    out!("{zeros:?}");
}
```

قراءة `days[10]` توقف البرنامج بخطأ واضح بدل قراءة ذاكرة عشوائية. للقوائم التي
تكبر استخدم `Vec` ([المجموعات](../everyday/collections.md)).
