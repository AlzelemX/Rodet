# الدوال

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let sum = add(2, 3);
    out!("{sum}");
}
```

- `fn add` — الاسم.
- `(a: i32, b: i32)` — المعاملات، ولكل واحد نوعه. الأنواع مطلوبة هنا: هي وعد
  الدالة لمن يستدعيها.
- `-> i32` — نوع القيمة التي ترجعها. بدون `->` لا ترجع شيئًا.
- `a + b` — **آخر تعبير، بدون `;`، هو النتيجة.**

## آخر سطر هو النتيجة

```rust
fn square(n: i32) -> i32 {
    n * n        // بدون `;` ← هذه القيمة تُرجَع
}

fn square_too(n: i32) -> i32 {
    return n * n; // `return` تعمل أيضًا؛ استخدمها للخروج مبكرًا
}

fn main() {
    out!("{} {}", square(4), square_too(5));
}
```

علامة `;` تحوّل التعبير إلى جملة لا تعطي شيئًا. كتابة `n * n;` في `square`
خطأ: الدالة وعدت بـ `i32` ولا تعطي شيئًا.

> في محرر DEVR+ تظهر علامة **↩** بعد القيمة التي ترجعها الدالة، فترى النتيجة
> مباشرة.

## الكتل تعابير أيضًا

```rust
fn main() {
    let grade = 85;
    let label = if grade >= 90 { "excellent" } else { "good" };

    let area = {
        let w = 3;
        let h = 4;
        w * h
    };
    out!("{label} {area}");
}
```

## إضافتان من Rodet

يمكن استدعاء الدوال في Rodet بأسماء المعاملات، ويمكن أن يكون للمعاملات
قيم افتراضية:

```rust
fn rect(width: u32, height: u32 = 1) -> u32 {
    width * height
}

fn main() {
    out!("{}", rect(width = 3, height = 4)); // 12
    out!("{}", rect(5));                     // 5، و height = 1
}
```

الفصلان التاليان يشرحانهما.
