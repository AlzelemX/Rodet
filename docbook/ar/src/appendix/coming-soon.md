اليوم**، والكتابة النهائية قد تتغير. القائمة المحدّثة في

## `data`: نوع واحد للـ struct والـ enum

كلمة واحدة لـ "هذا وذاك" و"هذا أو ذاك"، مع حقول مشتركة بين كل الأنواع:

```rust,ignore
data Shape {
    color: Color,              // كل Shape له لون
    | Circle { radius: f64 }
    | Rect { w: f64, h: f64 }
}
```

`struct` و`enum` باقيتان؛ و`data` لما تحتاج الاثنين.

## match المسماة

`match` هي أيضًا دالة، للقواعد التي تستخدمها في أكثر من مكان:

```rust,ignore
match price(size: Size) -> u32 {
    Size::Small => 10,
    Size::Big => 20,
}
```

## لا مزيد من `'a`

مصادر الاستعارة و`_a` تحل محل معظم الأعمار الآن. الخطة إزالة `'a` تمامًا،
بما في ذلك المكتبة القياسية ورسائل الأخطاء.

## رسائل أخطاء بأسلوب Rust++

أخطاء المترجم تعرض كتابة Rust++ (`&{x}`، `_a`) في اقتراحاتها.
