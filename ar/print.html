المقدمة

🌐 Read this book in English

Rust++ لغة برمجة مبنية من Rust 1.101. تحتفظ بكل ما يجعل Rust جيدة — سرعة مثل C، بدون جامع نفايات (garbage collector)، وبدون انهيارات بسبب الاستخدام الخاطئ للذاكرة — وتغيّر الأجزاء التي تجعل Rust صعبة القراءة وبطيئة التعلم.

fn greet(name: &str = "world", times: u32 = 1) {
    for _ in 0..times {
        out!("Hello, {name}!");
    }
}

fn main() {
    greet();
    greet("Rust++", times = 2);
}

تثبيت Rust++

ويندوز

  1. نزّل rustup++_init.exe من آخر إصدار.
  2. افتحه بضغطتين. يثبّت Rust++ في %USERPROFILE%\.rustpp ويضيفها إلى متغير PATH.
  3. إذا كانت أدوات Visual Studio C++ Build Tools غير موجودة، يعرض عليك تثبيتها. وافق: برامج ويندوز تُربط بأداة الربط من مايكروسوفت.

لينكس وماك

curl -fsSL https://github.com/AlzelemX/Rust-/releases/latest/download/rustup++_init.sh | sh

تحتاج أيضًا أداة ربط للغة C: xcode-select --install على الماك، أو build-essential (أوبونتو/ديبيان) / gcc على لينكس.

المحرر

استخدم DEVR+، المحرر المصنوع لـ Rust++: يعرف كل الكتابة الجديدة، ويعرض الأخطاء أثناء الكتابة، ويشغّل مشروعك بزر F5.

تأتي Rust++ أيضًا مع rust++-analyzer، محلل اللغة الذي يستخدمه DEVR+. المحررات الأخرى يمكنها استخدامه أيضًا: في VS Code ثبّت إضافة rust-analyzer واجعل الإعداد rust-analyzer.server.path يشير إلى rust++-analyzer في ~/.rustpp/bin (%USERPROFILE%\.rustpp\bin على ويندوز).

مرحبا يا عالم!

أنشئ ملفًا اسمه main.rs:

fn main() {
    out!("Hello, world!");
}

ترجمه وشغّله:

> rustc main.rs
> ./main          (on Windows: .\main.exe)
Hello, world!

معنى كل جزء

  • fn main() — دالة اسمها main. كل برنامج يبدأ من هنا.
  • { ... } — جسم الدالة.
  • out!("...") — يطبع سطرًا. علامة ! تعني أن out! ماكرو: كود يكتب كودًا عنك.
  • ; — تنهي الجملة.

جديد في Rust++: out! يطبع سطرًا. يعمل تمامًا مثل println! في Rust، وprintln! ما زال يعمل أيضًا.

طباعة القيم

ضع {} في المكان الذي تريد فيه القيمة، أو اسم المتغير داخل {}:

fn main() {
    let name = "Sara";
    let age = 25;

    out!("{name} is {age} years old");
    out!("{} + {} = {}", 2, 3, 2 + 3);
    out!();                        // سطر فارغ
    out!("{:?}", [1, 2, 3]);       // {:?} يطبع القوائم والبيانات الأخرى
    out!("{:.2}", 3.14159);        // رقمان بعد الفاصلة: 3.14
}
Sara is 25 years old
2 + 3 = 5

[1, 2, 3]
3.14

العربية

من الإعدادات (Ctrl+,) اختر اللغة: العربية. يصبح المحرر كله بالعربي: القوائم والأوامر، ورسائل المترجم، والإصلاحات السريعة، ونصائح السرعة، وشرح المكتبة القياسية، وهذا الكتاب. الكود نفسه يبقى من اليسار إلى اليمين.

العربية موجودة داخل Rust++ نفسها، وليس في المحرر فقط:

  • رسائل المترجم. يتكلم rustc وcargo بالعربي عندما يكون متغير البيئة RUSTPP_LANG يساوي ar (يضبطه DEVR+ تلقائيًا، وفي الطرفية التي بداخله أيضًا). من أي طرفية: RUSTPP_LANG=ar cargo build (في PowerShell: $env:RUSTPP_LANG="ar"; cargo build). الأسماء والأنواع والكود داخل الرسائل تبقى كما هي.
  • شرح المكتبة القياسية. كل عنصر موثّق في std وcore وalloc له شرح بالعربي بجانب الإنجليزي في نفس تعليق التوثيق. Option وResult وString وVec وHashMap وماكروهات الطباعة مشروحة كاملة بالعربي، والباقي ملخص قصير حاليًا. يعرض المحلل (analyzer) اللغة التي اخترتها (الإعداد rustpp.language: en أو ar)، وأمثلة الكود تظهر في اللغتين.

أول مشروع

  1. مشروع Rust++ جديد… في صفحة البداية (أو Ctrl+Shift+P ← Cargo: مشروع Rust++ جديد).
  2. اضغط F5: يبنيه Cargo ويشغّله في الطرفية بالأسفل.
  3. تظهر الأخطاء أثناء الكتابة؛ والضغط على ملف:سطر باللون الأحمر في الطرفية يفتح الملف عند ذلك السطر.

ملف main.js يصدّر الدالة activate التي تستقبل المحرر باسم devr:

// @ts-check
/** @param {import('./devr').Devr} devr */
export function activate(devr) {
  devr.addTranslations({ 'Hello!': 'مرحبًا!' });

  devr.commands.register({
    id: 'my-plugin.hello',
    title: 'My Plugin: Say Hello',
    key: 'Ctrl+Alt+H',
    run: () => devr.ui.toast(devr.t('Hello!'), 'success'),
  });

  const lines = devr.ui.addStatusItem({ icon: 'list-ordered', align: 'right' });
  devr.editor.onChange(() => lines.set(String(devr.editor.model?.getLineCount() ?? '')));
}

احفظ أي ملف من ملفات الإضافة فتُعاد تلقائيًا: عدّل، احفظ، شاهد. كل ما أضافته الإضافة يُزال عند إيقافها أو إعادة تحميلها؛ وما تصنعه بـ Monaco مباشرة أضفه إلى devr.subscriptions.

المتغيرات

أنشئ متغيرًا بـ let:

fn main() {
    let x = 5;
    out!("x = {x}");
}

المتغيرات لا تتغير إلا إذا قلت ذلك

fn main() {
    let x = 5;
    x = 6; // خطأ: لا يمكن تغيير `x` مرتين: المتغير ليس `mut`
}

أضف mut (قابل للتغيير) ليسمح للمتغير أن يتغير:

fn main() {
    let mut count = 0;
    count = count + 1;
    count += 1;
    out!("count = {count}"); // 2
}

لماذا ليست mut هي الأصل؟ عندما لا تتغير القيمة، لا تحتاج أبدًا أن تبحث عمّن غيّرها. معظم المتغيرات لا تتغير أبدًا، فتبرز القليلة التي عليها mut.

كتابة النوع بنفسك

Rust++ تستنتج النوع عنك، لكن يمكنك كتابته بعد ::

fn main() {
    let age: u32 = 30;
    let price: f64 = 9.99;
    let name: &str = "Ali";
    out!("{name}, {age}, {price}");
}

تذكّر: : تعني “نوعه”، و**= تعني “قيمته”**. Rust++ تحافظ على هذين المعنيين في كل مكان، أيضًا في الوسائط بالاسم والقيم الافتراضية.

التظليل (Shadowing)

let جديد بنفس الاسم يصنع متغيرًا جديدًا يخفي القديم. ويمكن أن يكون من نوع مختلف:

fn main() {
    let input = "42";
    let input: i32 = input.parse().unwrap();
    out!("{}", input + 1); // 43
}

الثوابت

قيم لا تتغير أبدًا في البرنامج كله. النوع مطلوب، والاسم بأحرف كبيرة:

const MAX_PLAYERS: u32 = 4;
const GAME: &_static str = "Space";

fn main() {
    out!("{GAME}: up to {MAX_PLAYERS} players");
}

&_static str تعني “نص يعيش طوال البرنامج”؛ انظر الأعمار المسماة.

الأنواع

لكل قيمة نوع. النوع يخبر المترجم كم تحتاج القيمة من الذاكرة وماذا يمكنك أن تفعل بها.

الأرقام

النوعيحملمثال
i32أعداد صحيحة، من −2 147 483 648 إلى 2 147 483 647 (الافتراضي)-7
i64أعداد صحيحة أكبر9_000_000_000
u8، u32، u64أعداد صحيحة، لا تكون سالبة أبدًا255
usizeالأحجام والمواضع في القوائمv.len()
f64أعداد بفاصلة عشرية (الافتراضي)3.14
f32مثل f64 لكن أصغر وأقل دقة1.5

i = يمكن أن يكون سالبًا، u = بدون إشارة (من 0 فما فوق)، والرقم = عدد البِتّات.

fn main() {
    let a = 10;           // i32
    let b = 3.0;          // f64
    let big = 1_000_000;  // علامة _ تجعل الأرقام الكبيرة سهلة القراءة

    out!("{}", a / 3);    // 3   (قسمة أعداد صحيحة)
    out!("{}", a % 3);    // 1   (باقي القسمة)
    out!("{}", b / 2.0);  // 1.5
    out!("{}", a as f64 / 4.0); // 2.5  (`as` يحوّل النوع)
    out!("{big}");
}

الأرقام من أنواع مختلفة لا تختلط بالخطأ: a + b في المثال خطأ حتى تحوّل واحدًا منهما بـ as. لا ضياع للدقة بدون أن تعلم.

صح وخطأ (true و false)

fn main() {
    let ready: bool = true;
    let big = 10 > 5; // true
    out!("{} {} {}", ready && big, ready || false, !ready);
}

الحروف والنصوص

fn main() {
    let letter: char = 'R';     // حرف واحد، بين علامتي تنصيص مفردتين
    let arabic = 'ع';           // أي لغة، وأي رمز تعبيري
    let fixed: &str = "hello";  // نص مكتوب في البرنامج
    let mut owned = String::from("hello"); // نص يمكن تكبيره
    owned.push_str(", world");

    out!("{letter} {arabic} {fixed} {owned}");
    out!("{}", owned.len()); // الطول بالبايت: 12
}

الفرق بين &str وString مشروح في الملكية. الآن يكفي: "..." من النوع &str؛ واستخدم String عندما يتغير النص.

الصفوف (tuples) والمصفوفات

fn main() {
    let point: (i32, i32) = (3, 4);   // صف: مجموعة ثابتة، أي أنواع
    let (x, y) = point;               // فكّه إلى أجزاء
    out!("x={x} y={y} first={}", point.0);

    let days = ["Sat", "Sun", "Mon"]; // مصفوفة: طول ثابت، نوع واحد
    out!("{} of {}", days[0], days.len());

    let zeros = [0; 5];               // [0, 0, 0, 0, 0]
    out!("{zeros:?}");
}

قراءة days[10] توقف البرنامج بخطأ واضح بدل قراءة ذاكرة عشوائية. للقوائم التي تكبر استخدم Vec (المجموعات).

الدوال

fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let sum = add(2, 3);
    out!("{sum}");
}
  • fn add — الاسم.
  • (a: i32, b: i32) — المعاملات، ولكل واحد نوعه. الأنواع مطلوبة هنا: هي وعد الدالة لمن يستدعيها.
  • -> i32 — نوع القيمة التي ترجعها. بدون -> لا ترجع شيئًا.
  • a + b — آخر تعبير، بدون ;، هو النتيجة.

آخر سطر هو النتيجة

fn square(n: i32) -> i32 {
    n * n        // بدون `;` ← هذه القيمة تُرجَع
}

fn square_too(n: i32) -> i32 {
    return n * n; // `return` تعمل أيضًا؛ استخدمها للخروج مبكرًا
}

fn main() {
    out!("{} {}", square(4), square_too(5));
}

علامة ; تحوّل التعبير إلى جملة لا تعطي شيئًا. كتابة n * n; في square خطأ: الدالة وعدت بـ i32 ولا تعطي شيئًا.

في محرر DEVR+ تظهر علامة ↩ بعد القيمة التي ترجعها الدالة، فترى النتيجة مباشرة.

الكتل تعابير أيضًا

fn main() {
    let grade = 85;
    let label = if grade >= 90 { "excellent" } else { "good" };

    let area = {
        let w = 3;
        let h = 4;
        w * h
    };
    out!("{label} {area}");
}

إضافتان من Rust++

يمكن استدعاء الدوال في Rust++ بأسماء المعاملات، ويمكن أن يكون للمعاملات قيم افتراضية:

fn rect(width: u32, height: u32 = 1) -> u32 {
    width * height
}

fn main() {
    out!("{}", rect(width = 3, height = 4)); // 12
    out!("{}", rect(5));                     // 5، و height = 1
}

الفصلان التاليان يشرحانهما.

الوسائط بالاسم

جديد في Rust++: عند استدعاء دالة، اكتب name = value لتحدد أي معامل يأخذ أي قيمة.

fn transfer(from: &str, to: &str, amount: u32) {
    out!("{amount} from {from} to {to}");
}

fn main() {
    transfer("Ali", "Sara", 100);                      // أيها أيها؟
    transfer(from = "Ali", to = "Sara", amount = 100); // واضح
    transfer(amount = 100, to = "Sara", from = "Ali"); // بأي ترتيب
}

الاستدعاءات الثلاثة تفعل نفس الشيء. الاستدعاء بالأسماء أوضح في القراءة، ولا يمكنك أن تبدّل from وto بالخطأ.

بالترتيب أولًا، ثم بالاسم

يمكنك إعطاء القيم الأولى بالترتيب وتسمية الباقي:

fn area(width: u32, height: u32) -> u32 {
    width * height
}

fn main() {
    out!("{}", area(3, height = 4));
}

بعد أول قيمة بالاسم، يجب أن تكون كل القيم التالية بالاسم:

fn area(width: u32, height: u32) -> u32 {
    width * height
}

fn main() {
    area(width = 3, 4); // خطأ: قيمة بالترتيب بعد قيمة بالاسم
}

الدوال المرتبطة والمُنشئات

الوسائط بالاسم تعمل مع الدوال المرتبطة (methods) ومع Type::new أيضًا:

struct Window {
    width: u32,
    height: u32,
}

impl Window {
    fn new(width: u32, height: u32) -> Window {
        Window { width, height }
    }

    fn resize(&mut self, width: u32, height: u32) {
        self.width = width;
        self.height = height;
    }
}

fn main() {
    let mut w = Window::new(width = 800, height = 600);
    w.resize(height = 1080, width = 1920);
    out!("{}x{}", w.width, w.height);
}

أخطاء يكتشفها المترجم

ما تكتبهالخطأ
area(widht = 3, height = 4)هذه الدالة ليس لها معامل اسمه widht
area(3, width = 4)المعامل width أُعطي أكثر من مرة
area(width = 3)لم تُعطَ قيمة للمعامل height

لماذا = وليس :

في Rust++، : تعني دائمًا “نوعه” (let x: u32) و= تعني دائمًا “قيمته” (let x = 5). الوسيط بالاسم يعطي قيمة، لذلك يستخدم =.

التكلفة

لا شيء. المترجم يعيد القيم إلى ترتيبها الصحيح قبل بناء البرنامج؛ والنتيجة مثل الاستدعاء بالترتيب تمامًا.

القيم الافتراضية

جديد في Rust++: يمكن أن يكون للمعامل قيمة افتراضية: name: Type = value. اتركه عند الاستدعاء فتُستخدم القيمة الافتراضية.

fn connect(host: &str, port: u16 = 443, secure: bool = true) {
    out!("{host}:{port} secure={secure}");
}

fn main() {
    connect("example.com");                       // المنفذ 443، آمن
    connect("example.com", 8080);                 // آمن
    connect("localhost", port = 3000, secure = false);
    connect("localhost", secure = false);         // المنفذ 443
}
example.com:443 secure=true
example.com:8080 secure=true
localhost:3000 secure=false
localhost:443 secure=false

مع الوسائط بالاسم يمكنك ترك أي معامل له قيمة افتراضية، وليس الأخيرة فقط: connect("localhost", secure = false) يبقي المنفذ الافتراضي.

داخل الأنواع

القيم الافتراضية تعمل في كتل impl أيضًا، فلا تحتاج دوالًا كثيرة مثل new_with_...:

struct Counter {
    value: i64,
    step: i64,
}

impl Counter {
    fn new(start: i64 = 0, step: i64 = 1) -> Counter {
        Counter { value: start, step }
    }

    fn tick(&mut self, times: i64 = 1) {
        self.value += self.step * times;
    }
}

fn main() {
    let mut a = Counter::new();
    a.tick();
    a.tick(times = 5);
    out!("{}", a.value); // 6

    let b = Counter::new(step = 10);
    out!("{}", b.value + b.step); // 10
}

القواعد

  • القيمة الافتراضية يجب أن تكون ثابتة: أرقام، "نص"، true، 'c'، None، ثوابت، وعمليات حسابية عليها (MAX / 2).

    fn hello(name: String = String::from("world")) {} // خطأ: ليست ثابتة

fn main() {}

    لقيمة افتراضية نصية، خذ &str بدلًا من String: fn hello(name: &str = "world").

  • مسموحة في الدوال وفي impl Type { ... }. ليست في الـ trait بعد.

  • المعاملات التي ليس لها قيمة افتراضية يجب إعطاؤها.

التكلفة

لا شيء. كل قيمة افتراضية تُحفظ مرة واحدة كثابت مخفي، والاستدعاء الذي يترك المعامل يستخدم ذلك الثابت كأنك كتبته بنفسك.

التحكم في سير البرنامج

if

fn main() {
    let temp = 38;

    if temp > 40 {
        out!("very hot");
    } else if temp > 30 {
        out!("hot");
    } else {
        out!("nice");
    }

    // `if` تعطي قيمة
    let wear = if temp > 30 { "t-shirt" } else { "jacket" };
    out!("{wear}");
}

الشرط يجب أن يكون bool. كتابة if count { ... } مع رقم خطأ: اكتب if count != 0.

loop و while و for

fn main() {
    // loop: للأبد، حتى `break`. و`break value` يعطي قيمة.
    let mut n = 1;
    let first_big = loop {
        n *= 2;
        if n > 100 { break n; }
    };
    out!("{first_big}"); // 128

    // while: ما دام الشرط صحيحًا
    let mut left = 3;
    while left > 0 {
        out!("{left}...");
        left -= 1;
    }

    // for: على مدى أو قائمة
    for i in 0..3 {          // 0، 1، 2
        out!("i = {i}");
    }
    for i in 1..=3 {         // 1، 2، 3
        out!("i = {i}");
    }
    for name in ["Ali", "Sara"] {
        out!("hi {name}");
    }
}

استخدم for كلما أمكنك: لا يمكن أن تتجاوز نهاية القائمة. وcontinue تنتقل إلى الدورة التالية.

match

match تقارن القيمة بأنماط، من الأعلى إلى الأسفل، وتنفذ أول نمط يطابق:

fn main() {
    let code = 404;
    let text = match code {
        200 => "OK",
        301 | 302 => "moved",          // واحد من الاثنين
        400..=499 => "your mistake",   // مدى
        _ => "something else",         // أي شيء متبقٍّ
    };
    out!("{text}");
}

يجب أن تغطي match كل القيم الممكنة؛ و_ تلتقط الباقي. إذا نسيت حالة، لا يُترجم البرنامج. هذا مفيد جدًا مع التعدادات.

الملكية

الملكية هي طريقة Rust++ في إدارة الذاكرة بدون جامع نفايات وبدون أن تستدعي free بنفسك. هي الفكرة الوحيدة التي تجعل Rust++ سريعة وآمنة معًا، فخذ وقتك مع هذا الفصل.

ثلاث قواعد

  1. لكل قيمة مالك واحد: المتغير الذي يحملها.
  2. عندما يختفي المالك (تنتهي كتلة { } الخاصة به)، تُحرَّر القيمة.
  3. إعطاء القيمة لغيرك ينقلها: المتغير القديم لا يستطيع استخدامها بعد ذلك.
fn main() {
    {
        let s = String::from("hello"); // s يملك النص
        out!("{s}");
    }                                  // انتهت الكتلة: حُرِّر النص
}

لا تسرّب للذاكرة (القيمة تُحرَّر دائمًا) ولا تحرير مزدوج (مالك واحد فقط يحررها). المترجم يتحقق من هذا؛ ولا يكلف شيئًا وقت التشغيل.

النقل

fn main() {
    let a = String::from("hello");
    let b = a;           // النص ينتقل من `a` إلى `b`
    out!("{a}");         // خطأ: استعارة `a` بعد نقله
}

لماذا؟ لو امتلك a وb النص معًا، لحرّره كل منهما. لذلك يعطي a النص ويصبح غير قابل للاستخدام.

نفس الشيء يحدث عندما تعطي قيمة لدالة:

fn shout(text: String) {
    out!("{}!", text.to_uppercase());
}   // يُحرَّر `text` هنا

fn main() {
    let msg = String::from("hi");
    shout(msg);           // `msg` ينتقل إلى الدالة
    // out!("{msg}");     // خطأ: `msg` نُقل
}

Copy: القيم الصغيرة تُنسخ ولا تُنقل

الأرقام وbool وchar، والصفوف والمصفوفات منها، صغيرة، فتُنسخ بدلًا من النقل:

fn main() {
    let x = 5;
    let y = x;           // نسخ
    out!("{x} {y}");     // الاثنان يعملان
}

clone: النسخ عن قصد

لتحصل فعلًا على نسختين من String أو Vec، اطلب ذلك بـ .clone(). يظهر في الكود، فترى دائمًا أين تُنسخ الذاكرة:

fn main() {
    let a = String::from("hello");
    let b = a.clone();
    out!("{a} {b}");
}

الفرق بين String و &str

  • String يملك نصه. يمكن أن يكبر ويتغير.
  • &str يستعير نصًا يملكه غيره (String، أو نص مكتوب في البرنامج).

معظم الدوال تحتاج فقط أن تقرأ النص، فتأخذ &str. هذه هي الاستعارة، موضوع الفصل التالي.

الاستعارة

نقل القيمة إلى كل دالة تقرؤها سيكون مزعجًا. بدلًا من ذلك تُعيرها: &value تصنع مرجعًا، مؤشرًا يستعير القيمة بدون أن يملكها.

fn length(text: &String) -> usize {
    text.len()
}   // `text` مستعار فقط: لا يُحرَّر شيء

fn main() {
    let s = String::from("hello");
    let n = length(&s);   // نعير `s`
    out!("{s} has {n} bytes"); // `s` ما زال لنا
}

التعديل عبر الاستعارة: &mut

& تعير للقراءة. و&mut تعير للتعديل:

fn add_world(text: &mut String) {
    text.push_str(", world");
}

fn main() {
    let mut s = String::from("hello");
    add_world(&mut s);
    out!("{s}"); // hello, world
}

قاعدة الاستعارة

في أي لحظة يمكن أن يكون عندك إما

  • أي عدد من & (قرّاء)، أو
  • &mut واحدة فقط (كاتب واحد)،

لكن ليس الاثنين معًا.

fn main() {
    let mut list = vec![1, 2, 3];
    let first = &list[0];   // قارئ
    list.push(4);           // كاتب والقارئ ما زال موجودًا: خطأ
    out!("{first}");
}

هذا ليس تشددًا: push قد تنقل القائمة إلى مكان أكبر في الذاكرة، فيصبح first مشيرًا إلى ذاكرة محررة. في C++ يُترجم هذا ثم ينهار لاحقًا؛ وفي Rust++ لا يُترجم.

الاستعارة تنتهي بعد آخر استخدام لها، لذلك هذا صحيح:

fn main() {
    let mut list = vec![1, 2, 3];
    let first = list[0];    // نسخة من الرقم، وليست استعارة
    list.push(4);
    out!("{first} {list:?}");
}

المرجع لا يعيش أطول من قيمته

fn main() {
    let r;
    {
        let s = String::from("short life");
        r = &s;
    }               // يُحرَّر `s` هنا...
    out!("{r}");    // ...فسيشير `r` إلى لا شيء: خطأ
}

عندما ترجع الدالة مرجعًا، يحتاج المترجم أن يعرف من أي قيمة يستعير، ليتحقق من هذه القاعدة عند الاستدعاء. في Rust هذا ما تفعله الأعمار ('a). في Rust++ طريقة أسهل: الفصل التالي.

مصادر الاستعارة

جديد في Rust++: عندما ترجع الدالة مرجعًا، اكتب من أي المعاملات تستعير: &{x, y} T.

fn longest(x: &str, y: &str) -> &{x, y} str {
    if x.len() >= y.len() { x } else { y }
}

fn main() {
    let a = String::from("apple");
    let b = String::from("fig");
    out!("{}", longest(&a, &b)); // apple
}

اقرأ -> &{x, y} str هكذا: ترجع &str مستعارًا من x أو من y. الآن يعرف المترجم أن النتيجة صالحة فقط ما دام a وb موجودين.

فقط المعاملات المهمة

fn pick(list: &Vec<i32>, index: &usize) -> &{list} i32 {
    &list[*index]
}

fn main() {
    let numbers = vec![10, 20, 30];
    let x = {
        let i = 1;
        pick(&numbers, &i)   // يُحرَّر `i` بعد هذه الكتلة...
    };
    out!("{x}");             // ...وهذا صحيح: x يستعير من `numbers` فقط
}

لأن النتيجة &{list} i32، يعرف المترجم أنها لا تستعير من index. المعلومة الدقيقة تعني أخطاء خاطئة أقل.

في أي مكان من نوع الإرجاع

fn first_word(text: &mut String) -> (&{text} str, usize) {
    let end = text.find(' ').unwrap_or(text.len());
    (&text[..end], end)
}

fn get<T>(items: &[T], i: usize) -> Option<&{items} T> {
    items.get(i)
}

fn main() {
    let mut s = String::from("hello world");
    let (w, n) = first_word(&mut s);
    out!("{w} {n}");
    out!("{:?}", get(&[1, 2, 3], 2)); // Some(3)
}

self

في الدوال المرتبطة، self مصدر مثل أي مصدر آخر:

struct Library {
    books: Vec<String>,
}

impl Library {
    fn first(&self) -> &{self} str {
        &self.books[0]
    }

    fn first_or(&self, other: &str, use_other: bool) -> &{self, other} str {
        if use_other { other } else { &self.books[0] }
    }
}

fn main() {
    let lib = Library { books: vec![String::from("Dune")] };
    out!("{} {}", lib.first(), lib.first_or("none", true));
}

هل أحتاجها دائمًا؟

لا. مثل Rust، عندما تأخذ الدالة مرجعًا واحدًا، أو تأخذ &self، يعرف المترجم من أين تأتي النتيجة:

fn trim_dots(text: &str) -> &str {    // مصدر واحد فقط: لا حاجة لـ {..}
    text.trim_matches('.')
}

fn main() {
    out!("{}", trim_dots("..hi.."));
}

اكتب &{...} عندما يكون هناك مرجعان أو أكثر يمكن الاختيار بينها.

القواعد

  • كل اسم يجب أن يكون معاملًا من نوع مرجع (&T أو &mut T)، أو self.
  • لا تكلفة وقت التشغيل: المترجم يحوّل &{x, y} إلى أعمار ويتحقق من نفس القواعد تمامًا.

الأعمار المسماة

مصادر الاستعارة تكفي للدوال. يبقى مكان واحد يحتاج اسمًا لـ “كم تعيش الاستعارة”: struct يحمل مرجعًا.

جديد في Rust++: أسماء الأعمار تُكتب مثل الأسماء العادية التي تبدأ بـ _: _a، _text. و'static أصبحت _static.

struct Parser<_a> {
    input: &_a str,
    pos: usize,
}

impl<_a> Parser<_a> {
    fn new(input: &_a str) -> Parser<_a> {
        Parser { input, pos: 0 }
    }

    fn next_word(&mut self) -> Option<&_a str> {
        let rest = &self.input[self.pos..];
        let rest = rest.trim_start();
        if rest.is_empty() {
            return None;
        }
        let start = self.input.len() - rest.len();
        let end = rest.find(' ').unwrap_or(rest.len());
        self.pos = start + end;
        Some(&rest[..end])
    }
}

fn main() {
    let text = String::from("borrow without fear");
    let mut p = Parser::new(&text);
    while let Some(word) = p.next_word() {
        out!("{word}");
    }
}

اقرأ Parser<_a> هكذا: Parser يستعير شيئًا لمدة اسمها _a، و input: &_a str هكذا: input مستعار لتلك المدة. الـ Parser لا يمكن أن يعيش أطول من النص الذي يقرؤه؛ والمترجم يتحقق من ذلك.

_static

_static تعني “طوال البرنامج”. النص المكتوب في البرنامج نوعه &_static str:

const GREETING: &_static str = "salam";

fn pick_color(dark: bool) -> &_static str {
    if dark { "black" } else { "white" }
}

fn main() {
    out!("{GREETING} {}", pick_color(true));
}

وتعمل أيضًا كشرط، بمعنى “لا يحمل استعارات قصيرة العمر”:

fn keep<T: _static + std::fmt::Debug>(value: T) -> Box<dyn std::fmt::Debug + _static> {
    Box::new(value)
}

fn main() {
    out!("{:?}", keep(42));
}

القواعد

  • اسم العمر هو _ يتبعها حرف إنجليزي صغير: _a، _x، _input.
  • يُكتب داخل <...> وبعد &.
  • المتغير الذي اسمه _a يبقى متغيرًا عاديًا.
  • اسم يبدأ بـ _ ويتبعه :: أو ! أو < هو مسار عادي وليس عمرًا: _paths::Thing.
  • 'a من Rust ما زالت تعمل الآن. ستُزال؛ انظر قريبًا.

الـ struct يجمع قيمًا مترابطة تحت اسم واحد.

الدوال المرتبطة (methods)

الدوال التي تنتمي لنوع تُكتب في كتلة impl:

struct Rect {
    width: f64,
    height: f64,
}

impl Rect {
    // بدون `self`: تُستدعى هكذا Rect::new(...)
    fn new(width: f64, height: f64 = 1.0) -> Rect {
        Rect { width, height }
    }

    fn square(size: f64) -> Rect {
        Rect::new(width = size, height = size)
    }

    // &self: تقرأ القيمة
    fn area(&self) -> f64 {
        self.width * self.height
    }

    // &mut self: تغيّر القيمة
    fn scale(&mut self, by: f64 = 2.0) {
        self.width *= by;
        self.height *= by;
    }

    // self: تأخذ القيمة (تنتقل إلى الدالة)
    fn into_square(self) -> Rect {
        Rect::square(self.width.max(self.height))
    }
}

fn main() {
    let mut r = Rect::new(width = 3.0, height = 4.0);
    out!("{}", r.area());        // 12
    r.scale();
    out!("{}", r.area());        // 48
    r.scale(by = 0.5);
    let s = r.into_square();
    out!("{}", s.area());        // 16
    // لا يمكن استخدام r بعد الآن: into_square أخذته
}

كل نوع يمكن أن يحمل بيانات

كل نوع يمكن أن يحمل قيمه الخاصة:

enum Shape {
    Circle { radius: f64 },
    Rect { width: f64, height: f64 },
    Point,
}

impl Shape {
    fn area(&self) -> f64 {
        match self {
            Shape::Circle { radius } => 3.14159 * radius * radius,
            Shape::Rect { width, height } => width * height,
            Shape::Point => 0.0,
        }
    }
}

fn main() {
    let shapes = [
        Shape::Circle { radius: 1.0 },
        Shape::Rect { width: 2.0, height: 3.0 },
        Shape::Point,
    ];
    for s in &shapes {
        out!("{:.2}", s.area());
    }
}

يجب أن تعالج match كل نوع. أضف نوعًا جديدًا إلى Shape وسيعرض لك المترجم كل match تحتاج تحديثًا: لا تُنسى أي حالة.

Option: قيمة أو لا شيء

Rust++ ليس فيها null. القيمة التي قد تكون غير موجودة نوعها Option:

fn find_age(name: &str) -> Option<u32> {
    if name == "Sara" { Some(25) } else { None }
}

fn main() {
    match find_age("Sara") {
        Some(age) => out!("age {age}"),
        None => out!("unknown"),
    }

    // صيغ أقصر
    if let Some(age) = find_age("Ali") {
        out!("Ali is {age}");
    }
    let age = find_age("Ali").unwrap_or(0);
    out!("{age}");
}

لا يمكنك استخدام Option<u32> كأنه u32 بالخطأ: يجب أن تعالج None أولًا. هذا يزيل عائلة كاملة من الانهيارات.

السمات (trait) والأنواع العامة

الـ trait: ما الذي يستطيع النوع فعله

الـ trait قائمة دوال. النوع الذي يملك تلك الدوال يطبّق الـ trait.

trait Speak {
    fn name(&self) -> String;

    // دالة لها جسم هي قيمة افتراضية: يمكن للأنواع أن تبقيها أو تستبدلها
    fn greet(&self) -> String {
        format!("Hello from {}", self.name())
    }
}

struct Cat;
struct Robot {
    id: u32,
}

impl Speak for Cat {
    fn name(&self) -> String {
        String::from("a cat")
    }
}

impl Speak for Robot {
    fn name(&self) -> String {
        format!("robot #{}", self.id)
    }
    fn greet(&self) -> String {
        format!("BEEP. I AM {}", self.name().to_uppercase())
    }
}

fn main() {
    out!("{}", Cat.greet());
    out!("{}", Robot { id: 7 }.greet());
}

الأنواع العامة (Generics): دالة واحدة لأنواع كثيرة

<T> معامل نوع: مكان لـ “نوع ما”. وT: Speak تعني “أي نوع يطبّق Speak”:

trait Speak {
    fn name(&self) -> String;
}

struct Cat;
impl Speak for Cat {
    fn name(&self) -> String { String::from("cat") }
}

fn introduce<T: Speak>(thing: &T) {
    out!("This is {}", thing.name());
}

fn largest<T: PartialOrd + Copy>(items: &[T]) -> T {
    let mut best = items[0];
    for &item in items {
        if item > best {
            best = item;
        }
    }
    best
}

fn main() {
    introduce(&Cat);
    out!("{}", largest(&[3, 9, 2]));
    out!("{}", largest(&[1.5, 0.5]));
    out!("{}", largest(&['a', 'z', 'm']));
}

المترجم يصنع نسخة منفصلة ومحسّنة بالكامل من الدالة العامة لكل نوع تستخدمه. الأنواع العامة لا تكلف شيئًا وقت التشغيل.

fn main() {
    let prices = vec![12, 5, 40, 8, 25];

    let total: u32 = prices.iter().sum();
    let cheap: Vec<u32> = prices.iter().filter(|&&p| p < 20).cloned().collect();

}

الأخطاء

في Rust++ نوعان من الأخطاء:

  • العيوب (bugs) التي يجب ألا تحدث أبدًا: يتوقف البرنامج بـ panic!.
  • الفشل المتوقع، مثل ملف غير موجود أو مدخل خاطئ: الدالة ترجع Result ومن يستدعيها يقرر ماذا يفعل.

Result

fn divide(a: f64, b: f64) -> Result<f64, String> {
    if b == 0.0 {
        Err(String::from("can't divide by zero"))
    } else {
        Ok(a / b)
    }
}

fn main() {
    match divide(10.0, 4.0) {
        Ok(v) => out!("result {v}"),
        Err(e) => out!("error: {e}"),
    }
    match divide(1.0, 0.0) {
        Ok(v) => out!("result {v}"),
        Err(e) => out!("error: {e}"),
    }
}

Result<T, E> إما Ok(value) أو Err(error). مثل Option، لا يمكنك استخدام القيمة بدون معالجة الخطأ أولًا.

علامة ? : مرّر الخطأ للأعلى

داخل دالة ترجع Result، علامة ? بعد استدعاء تعني: إذا كان هذا خطأ، أرجعه الآن؛ وإلا أعطني القيمة.

fn parse_pair(text: &str) -> Result<(i32, i32), std::num::ParseIntError> {
    let mut parts = text.split(',');
    let a = parts.next().unwrap_or("").trim().parse::<i32>()?;
    let b = parts.next().unwrap_or("").trim().parse::<i32>()?;
    Ok((a, b))
}

fn main() {
    out!("{:?}", parse_pair("3, 4"));   // Ok((3, 4))
    out!("{:?}", parse_pair("3, x"));   // Err(ParseIntError { kind: InvalidDigit })
}

الوحدات (modules)

عندما يكبر البرنامج، قسّمه إلى وحدات. الوحدة مجموعة لها اسم من الدوال والأنواع والوحدات الأخرى.

mod shapes {
    pub struct Circle {
        pub radius: f64,
    }

    impl Circle {
        pub fn area(&self) -> f64 {
            PI * self.radius * self.radius
        }
    }

    const PI: f64 = 3.14159; // خاص: يُستخدم داخل `shapes` فقط
}

use shapes::Circle;

fn main() {
    let c = Circle { radius: 2.0 };
    out!("{:.2}", c.area());
}

  • use تجلب اسمًا إلى النطاق فلا تحتاج كتابة المسار كاملًا.
  • :: تفصل أجزاء المسار: shapes::Circle، std::collections::HashMap.
